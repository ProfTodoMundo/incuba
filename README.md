# Incuba

**Incuba** es una iniciativa de Analítica Aplicada para ayudar a emprendedores, profesionistas y pequeños negocios a construir una presencia digital profesional.

## Servicios

- Sitios web y landing pages
- Catálogos digitales
- Códigos QR
- Integración con WhatsApp
- Automatización
- Analítica y soluciones digitales
